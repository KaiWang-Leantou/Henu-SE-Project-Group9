## 2. 本轮做了什么

**后端（Sprint B）**
- `wb_board_version` 表与三类版本：`AUTO`（5 分钟/200 op）、`MANUAL`、`PRE_RESTORE`
- 回滚五步（先存当前态 → 覆盖 → 记 `board.restore` op → 落库 → 广播 `init`），历史只追加
- 归档 / 回收站 / 恢复 / 复制，归档板写入返回 `READ_ONLY`
- 房间内光标配色避让（同房间不撞色）
- 每日 03:00 版本 GC（保留最近 30 + 每天首个 + MANUAL 永久）

**前端（改版）**
- 主界面三入口：画画 / 联机 / 你画我猜（占位）
- `/draw`：全部 / 已归档 / 回收站 + 版本抽屉（存档、回滚）
- `/collab`：选板建房、归档板"复制后联机"、邀请链接
- 画布页移除"你画我猜"浮层；远端光标（颜色/昵称/淡出）
- 设置抽屉：光标颜色/透明度/大小/昵称/深色模式（localStorage）

**修复**
- 手动存档读到旧快照导致存成空板 → 改用内存实时快照
- 光标按哈希撞色 → 房间内避让分配
