# 05 · 接口示例（Sprint A）

> 前后端并行开发的对照表。所有 HTTP 接口都在 `/api` 下，返回统一信封。
> 契约依据：`docs/04-身份作品库与版本.md`。

## 0. 统一返回信封

```json
{ "code": "OK", "message": "ok", "data": { } }
```

失败时 HTTP 状态码同时置位（400/401/403/404/409/500），`data` 为 `null`：

```json
{ "code": "USERNAME_TAKEN", "message": "用户名已被占用", "data": null }
```

| `code` | HTTP | 场景 |
| :--- | :--- | :--- |
| `OK` | 200 | 成功 |
| `VALIDATION_ERROR` | 400 | 参数不合法 |
| `AUTH_REQUIRED` | 401 | 未登录 / token 缺失 |
| `TOKEN_EXPIRED` | 401 | token 过期 |
| `INVALID_CREDENTIALS` | 401 | 用户名或密码错误 |
| `FORBIDDEN` | 403 | 角色不足 |
| `NOT_FOUND` | 404 | 资源不存在 |
| `USERNAME_TAKEN` | 409 | 用户名重复 |
| `INTERNAL` | 500 | 服务端异常 |

## 1. 认证

### 1.1 注册

```http
POST /api/auth/register
Content-Type: application/json

{ "username": "zhangsan", "password": "Abc12345", "nickname": "张三" }
```

```json
{ "code": "OK", "message": "ok", "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": { "id": "u_7f3a21", "username": "zhangsan", "nickname": "张三", "guest": false }
}}
```

校验：用户名 `^[a-zA-Z0-9_]{4,32}$`；密码 ≥ 8 位且同时含字母和数字；昵称 1–20 字符（缺省取用户名）。

### 1.2 登录

```http
POST /api/auth/login

{ "username": "zhangsan", "password": "Abc12345" }
```

成功同上；失败 `401 INVALID_CREDENTIALS`（不区分"用户不存在"与"密码错误"）。

### 1.3 游客会话

```http
POST /api/auth/guest

{ "nickname": "路人甲" }
```

```json
{ "code": "OK", "message": "ok", "data": {
    "token": "eyJ...",
    "user": { "id": "u_ab12cd", "username": null, "nickname": "路人甲", "guest": true }
}}
```

游客 token 与正式用户同等有效，但：不能创建白板、不能存档、不能回滚；可以加入公开板协作。

### 1.4 游客升级

```http
POST /api/auth/upgrade
Authorization: Bearer <游客 token>

{ "username": "lisi", "password": "Abc12345", "nickname": "李四" }
```

返回新的正式 token；**`user.id` 不变**，此前参与的板、创建的草稿全部保留。

### 1.5 当前用户

```http
GET /api/auth/me
Authorization: Bearer <token>
```

```json
{ "code": "OK", "message": "ok", "data": {
    "id": "u_7f3a21", "username": "zhangsan", "nickname": "张三", "guest": false
}}
```

## 2. 作品库

### 2.1 列表

```http
GET /api/boards?scope=mine&status=active&q=动物&page=1&size=20
Authorization: Bearer <token>
```

| 参数 | 取值 | 默认 |
| :--- | :--- | :--- |
| `scope` | `mine`（我创建的）/ `joined`（我参与的）/ `all`（公开） | `mine` |
| `status` | `active` / `draft` / `archived` | `active` |
| `q` | 名称模糊搜索 | 空 |
| `page` / `size` | 分页，size ≤ 50 | 1 / 20 |

```json
{ "code": "OK", "message": "ok", "data": {
    "total": 3, "page": 1, "size": 20,
    "items": [
      { "id": "b_7f3a", "name": "动物速写", "role": "owner", "status": "active",
        "thumbnail": "data:image/webp;base64,UklGR...", 
        "lastSavedAt": "2026-11-13T12:31:05+08:00",
        "createdAt": "2026-11-10T09:00:00+08:00" }
    ]
}}
```

排序固定 `lastSavedAt DESC, createdAt DESC`。

### 2.2 新建

```http
POST /api/boards
Authorization: Bearer <token>

{ "name": "动物速写" }
```

```json
{ "code": "OK", "message": "ok", "data": {
    "id": "b_7f3a", "name": "动物速写", "role": "owner",
    "status": "draft", "createdAt": "2026-11-13T12:00:00+08:00" }}
```

- 游客调用 → `403 FORBIDDEN`（"登录后才能创建作品"）。
- 新建后自动写入 `wb_board_member(owner)`。

### 2.3 详情

```http
GET /api/boards/b_7f3a
Authorization: Bearer <token>
```

```json
{ "code": "OK", "message": "ok", "data": {
    "id": "b_7f3a", "name": "动物速写", "status": "active", "public": true,
    "role": "owner",
    "owner": { "id": "u_7f3a21", "nickname": "张三" },
    "members": [ { "id": "u_7f3a21", "nickname": "张三", "role": "owner" } ],
    "lastSavedAt": "2026-11-13T12:31:05+08:00",
    "thumbnail": "data:image/webp;base64,..." }}
```

非成员访问私有板 → `403`。

### 2.4 改名

```http
PATCH /api/boards/b_7f3a
Authorization: Bearer <token>

{ "name": "动物速写 2" }
```

仅 `owner`，返回 204 或 `{ "code": "OK", "data": null }`。

### 2.5 缩略图

```http
PUT /api/boards/b_7f3a/thumbnail
Authorization: Bearer <token>

{ "dataUrl": "data:image/webp;base64,UklGR..." }
```

限制：`data:image/webp` 或 `image/png`，解码后 ≤ 256 KB。`EDITOR` 及以上可写。

## 3. WebSocket 鉴权

```
ws://localhost:8080/ws?token=<JWT>
```

或首帧带：

```json
{ "t": "join", "boardId": "b_7f3a", "lastSeq": 0, "token": "eyJ..." }
```

服务端解析顺序：query `token` → `join.token` → 无 token 时按匿名（仅 `wb.auth.allow-anonymous=true` 且板为公开）。

`init` 的 `me` 增加 `guest` 字段：

```json
{ "t": "init", "seq": 812, "doc": { }, 
  "me": { "id": "u_7f3a21", "name": "张三", "role": "owner", "guest": false },
  "members": [ ], "savedAt": "2026-11-13T12:31:05+08:00" }
```

新增服务端消息：

```json
{ "t": "saved", "seq": 812, "at": "2026-11-13T12:31:05+08:00" }
```

拒绝写入时的错误码新增 `AUTH_REQUIRED`、`READ_ONLY`。

## 4. 访问规则（后端必须实现）

| 场景 | 规则 |
| :--- | :--- |
| 加入已存在的公开板 | 任何有 token 的用户（含游客）→ `EDITOR` |
| 加入私有板 | 必须是成员；否则 `403` |
| 加入不存在的板 | 自动创建，`status=active`、`public=true`（**链接即分享**）；创建者是 `owner` |
| 写入（WS op） | 角色 ≥ `EDITOR`，且过 `BoardPlugin.canWrite` |
| 创建作品 / 缩略图 / 版本 | 必须是非游客 |
| 改名 / 归档 / 删除 | `owner` |

> **V1.5 的产品口径**：新建白板默认 `ACTIVE + 公开`，拿到链接的人都能进（和 Excalidraw 一致），作品库只列自己的。
> `DRAFT`（仅本人）与"私有/邀请"留到 Sprint B，届时新增发布接口再切换默认值。

## 5. 前端联调建议

- 后端没起时，作品库显示空态 + "无法连接服务器"，登录按钮给出错误提示，**不要白屏**。
- token 存 `localStorage.wb.token`，`user` 存 `localStorage.wb.user`，启动时先 `GET /api/auth/me` 校验。
- 所有 `/api` 请求带 `Authorization: Bearer`；401 时清 token 并跳登录页。
- 开发态由 Vite 代理 `/api` 与 `/ws` 到 `localhost:8080`，无跨域问题。

```powershell
curl.exe -s -X POST http://localhost:8080/api/boards -H "Content-Type: application/json" -H "Authorization: Bearer <token>" -d '{\"name\":\"动物速写\"}'
```
