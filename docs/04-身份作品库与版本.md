## 3. 身份与会话

### 3.1 用户表

```sql
CREATE TABLE wb_user (
  id            VARCHAR(32)  NOT NULL PRIMARY KEY,
  username      VARCHAR(32)  NULL,               -- 游客为 NULL
  password_hash VARCHAR(100) NULL,               -- BCrypt；游客为 NULL
  nickname      VARCHAR(50)  NOT NULL,
  avatar        VARCHAR(255) NULL,
  is_guest      TINYINT(1)   NOT NULL DEFAULT 1,
  status        VARCHAR(16)  NOT NULL DEFAULT 'ACTIVE',  -- ACTIVE / DISABLED
  created_at    DATETIME(3)  NOT NULL,
  last_login_at DATETIME(3)  NULL,
  UNIQUE KEY uk_username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.2 注册 / 登录

| 接口 | 入参 | 出参 |
| :--- | :--- | :--- |
| `POST /api/auth/register` | `username`, `password`, `nickname` | `token`, `user` |
| `POST /api/auth/login` | `username`, `password` | `token`, `user` |
| `POST /api/auth/guest` | `nickname?` | `token`, `user`（`isGuest=true`） |
| `POST /api/auth/upgrade` | `username`, `password`（需已登录的游客） | `token`, `user`（保留原 `id`） |
| `GET /api/auth/me` | — | `user` |
| `POST /api/auth/logout` | — | 204（V1 仅前端丢弃 token） |

- 密码：BCrypt（`spring-security-crypto`），强度 10。
- 用户名：`^[a-zA-Z0-9_]{4,32}$`；密码 ≥ 8 位且含字母数字。
- 失败统一返回 `401 INVALID_CREDENTIALS`，不区分"用户不存在/密码错"。

### 3.3 JWT

| 项 | 值 |
| :--- | :--- |
| 算法 | HS256，密钥来自 `WB_JWT_SECRET` 环境变量（**不得入库/入仓**） |
| 载荷 | `sub`(userId), `guest`(bool), `name`, `iat`, `exp` |
| 有效期 | 12 小时（课设不做 refresh，过期重新登录） |
| HTTP 传递 | `Authorization: Bearer <token>` |
| **WS 传递** | `GET /ws?token=<token>`，兼容既有 `join.token` 字段 |

WS 鉴权顺序：`?token` → `join.token` → 匿名游客（仅当 `wb.auth.allow-anonymous=true`）。

### 3.4 游客

- 首次访问调 `POST /api/auth/guest`，后端建 `is_guest=1` 用户，发 12h token。
- 游客**不能**创建作品、不能存档、不能回滚；可以加入公开板协作。
- 升级：`POST /api/auth/upgrade` 给当前游客补 `username/password_hash`，`id` 不变 → 之前参与的板、版本归属全部保留。

## 4. 白板归属与生命周期

### 4.1 表结构变更

```sql
ALTER TABLE wb_board
  ADD COLUMN status      VARCHAR(16) NOT NULL DEFAULT 'ACTIVE',  -- DRAFT/ACTIVE/ARCHIVED/TRASHED
  ADD COLUMN archived_at DATETIME(3) NULL,
  ADD COLUMN trashed_at  DATETIME(3) NULL,
  ADD COLUMN thumbnail   MEDIUMTEXT  NULL,
  ADD COLUMN last_saved_at DATETIME(3) NULL,
  MODIFY COLUMN owner_id VARCHAR(32) NOT NULL;                    -- 指向 wb_user.id

CREATE TABLE wb_board_member (
  board_id  VARCHAR(32) NOT NULL,
  user_id   VARCHAR(32) NOT NULL,
  role      VARCHAR(16) NOT NULL,          -- OWNER/EDITOR/VIEWER
  joined_at DATETIME(3) NOT NULL,
  PRIMARY KEY (board_id, user_id)
);
```

### 4.2 状态机

```
[*] → DRAFT ──发布──→ ACTIVE ──归档──→ ARCHIVED
                       │  ↑                │
              软删除   ↓  └────取消归档────┘
                    TRASHED ──30 天──→ [清除]
                       └──恢复──→ ACTIVE
```

| 状态 | 出现在作品库 | 可编辑 | 可访问 |
| :--- | :--- | :--- | :--- |
| `DRAFT` | 仅本人 | ✅ | 仅成员 |
| `ACTIVE` | 是 | ✅ | 成员 + 公开链接 |
| `ARCHIVED` | 分类页 | ❌ 只读 | 成员 |
| `TRASHED` | 回收站 | ❌ | 仅 owner |

> **V1.5 实现取舍**：新建白板直接置为 `ACTIVE + public`（链接即分享，与 Excalidraw 一致），
> 否则新建的板别人进不去、无法协作。`DRAFT` 的"仅本人"语义保留给 Sprint B 的"发布/私有"功能。

> 归档是**只读**不是删除；回收站 30 天后由定时任务物理清除。

## 5. 自动存稿（产品化）

技术上已有（2s 防抖 / 50 op 快照），本版要做的是**让它可见**：

1. `wb_board.last_saved_at` 每次快照写入时更新。
2. WS 新增 `saved {seq, at}` 消息，客户端右上角显示"已自动保存 12:31:05"。
3 断线重连后以服务端 `init` 为准，前端提示"已恢复到最新版本"。

## 6. 版本与回滚

### 6.1 表

```sql
CREATE TABLE wb_board_version (
  id         VARCHAR(32) PRIMARY KEY,
  board_id   VARCHAR(32) NOT NULL,
  version_no INT         NOT NULL,
  kind       VARCHAR(16) NOT NULL,        -- AUTO / MANUAL / PRE_RESTORE
  label      VARCHAR(100) NULL,
  doc_json   LONGTEXT    NOT NULL,
  doc_seq    BIGINT      NOT NULL,
  thumbnail  MEDIUMTEXT  NULL,
  author_id  VARCHAR(32) NULL,
  created_at DATETIME(3) NOT NULL,
  UNIQUE KEY uk_board_version (board_id, version_no),
  KEY idx_board_time (board_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 6.2 生成与保留

| 类型 | 触发 | 保留策略 |
| :--- | :--- | :--- |
| `AUTO` | 有改动且距上个 AUTO ≥ 5 分钟，或累计 ≥ 200 op | 最近 30 个 + 每天首个，30 天 |
| `MANUAL` | 用户点"存为版本"并命名 | 永久，单板 ≤ 100 |
| `PRE_RESTORE` | 每次回滚前自动写一份当前态 | 30 天 |

- 单板版本总数上限 200，超出按"最旧 AUTO → 最旧 PRE_RESTORE"顺序清理。
- GC 任务每日 03:00 执行；**`MANUAL` 永不自动删除**。

### 6.3 回滚语义

```
回滚(versionId)：
  ① 当前 doc 存为 PRE_RESTORE 版本
  ② 读取目标版本 doc，替换当前文档，seq = max(seq, 目标.doc_seq) + 1
  ③ 落一条 op：{t:"board.restore", versionId, versionNo}  → 可审计、可重放
  ④ 更新 wb_board.doc_json / doc_seq / last_saved_at
  ⑤ 向房间广播 init（强制全量重同步）
```

**历史只追加**：回滚不会删除任何版本，所以"回滚的回滚"永远可行。

### 6.4 并发注意

回滚期间房间可能有人正在画：由房间串行执行器执行回滚，执行前把 `seq` 递增并广播 `init`，客户端收到后丢弃本地 pending 命令（未 ack 的）——这与现有的重同步逻辑一致。

## 7. 作品库

- 入口：`/works` 页面，卡片式网格。
- 卡片内容：缩略图、名称、协作者头像、`最后保存` 时间、版本数。
- 排序：`last_saved_at desc`（默认）/ 名称 / 创建时间。
- 搜索：名称模糊匹配。
- 筛选：全部 / 我创建的 / 我参与的 / 已归档 / 回收站。
- 缩略图：前端在"存为版本 / 自动存稿"时用 `canvas.toDataURL('image/webp', 0.6)` 生成，≤ 512px 长边，随 REST 上传。

## 8. REST API 一览

| 方法 | 路径 | 说明 | 权限 |
| :--- | :--- | :--- | :--- |
| POST | `/api/auth/register` | 注册 | 匿名 |
| POST | `/api/auth/login` | 登录 | 匿名 |
| POST | `/api/auth/guest` | 游客会话 | 匿名 |
| POST | `/api/auth/upgrade` | 游客升级 | 游客 |
| GET | `/api/auth/me` | 当前用户 | 登录态 |
| GET | `/api/boards` | 作品列表（`scope/status/q/page/size`） | 登录 |
| POST | `/api/boards` | 新建白板 | 注册用户 |
| GET | `/api/boards/{id}` | 白板元数据 | 成员/公开 |
| PATCH | `/api/boards/{id}` | 改名 / 归档 / 取消归档 | OWNER |
| DELETE | `/api/boards/{id}` | 进回收站 | OWNER |
| POST | `/api/boards/{id}/trash/restore` | 从回收站恢复 | OWNER |
| PUT | `/api/boards/{id}/thumbnail` | 上传缩略图 | EDITOR+ |
| GET | `/api/boards/{id}/versions` | 版本时间轴 | 成员 |
| POST | `/api/boards/{id}/versions` | 手动存档 `{label, thumbnail}` | EDITOR+ |
| POST | `/api/boards/{id}/versions/{vid}/restore` | 回滚 | OWNER |

统一返回包（错误码与示例见 `docs/05-接口示例.md`）：

```json
{ "code": "OK", "message": "ok", "data": { } }
```

失败时 `code` 为字符串错误码（`USERNAME_TAKEN`、`FORBIDDEN`…）+ 对应 HTTP 状态码 + 中文 `message`（前端可直接展示）。

## 9. WS 协议增量

| 方向 | 消息 | 变化 |
| :--- | :--- | :--- |
| C→S | `join{boardId,lastSeq,token?}` | `token` 生效；游客 token 也可传 |
| S→C | `init{..., me:{id,name,role,guest}, savedAt}` | `me` 增加 `guest`，顶层增加 `savedAt` |
| S→C | `saved{seq, at}` | **新增**：快照落库后通知（前端显示"已保存"） |
| S→C | `board.reload{seq, reason}` | **新增**：回滚/归档/恢复后强制重同步（也可直接复用 `init`） |
| S→C | `error.code` 新增 `AUTH_REQUIRED` / `READ_ONLY` | 拒绝写入时更明确 |

## 10. 迁移与兼容

1. 现有 `u_system` 匿名板：启动迁移任务把 `owner_id` 置为 `NULL` 并标记 `status='DRAFT'`，任何登录用户可"认领"（`POST /api/boards/{id}/claim`，二期）。
2. 课设演示数据可直接清库重建，不强制兼容。
3. `application.yml` 拆 profile：`dev`（H2 file）/ `mysql`（生产）。**演示一律用 mysql profile**。

```yaml
# dev
spring.datasource.url: jdbc:h2:file:./data/wb;MODE=MySQL;AUTO_SERVER=TRUE
# mysql
spring.datasource.url: jdbc:mysql://127.0.0.1:3306/wb?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
```

**验收**：画 3 笔 → 存档 → 再画 3 笔 → 回滚到存档点 → 画布回到 3 笔；归档后只读；回收站恢复成功；重启后端数据仍在。
